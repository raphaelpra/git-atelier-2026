# `git commit` en 10 lignes

**À quoi ça sert** : enregistrer un état du projet.

**La forme courante** : `git commit -m "messsage du commit"`

**Un exemple qu'on peut taper** (testé dans `git-carnet`) :

```bash
git commit -m "exemple de commit" ...
```

**Le piège** ⚠️ : ne pas oublier la commande add pour ajouter le projet dans l'index.
