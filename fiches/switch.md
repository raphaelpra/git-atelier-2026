# `git <commande>` en 10 lignes

**À quoi ça sert** : changer de branche ou créer une nouvelle branche

**La forme courante** : `git switch [options] <branche>`

**Un exemple qu'on peut taper** (testé dans `git-carnet`) :

```bash
git switch -c nouvelle-branche
```

**Ce que ça affiche / ce que ça change** : crée nouvelle-branche et bascule dessus

**Le piège** ⚠️ : les modifications non validées empêchent de changer de branche

**Commande voisine** : `git checkout` – usages plus larges.
