# `git <commande>` en 10 lignes

**À quoi ça sert** : à fusionner deux branches

**La forme courante** : `git merge autrebranche`

**Un exemple qu'on peut taper** (testé dans `git-carnet`) :

```bash
git merge branche2
```

**Ce que ça affiche / ce que ça change** : ça fusionne les modifications de branche2 dans la branche dans laquelle on est.

**Le piège** ⚠️ : Il faut faire attention aux conflits quand des modifications se superposent.

**Commande voisine** : `git switch autre_branche` – Elle change de branche.
